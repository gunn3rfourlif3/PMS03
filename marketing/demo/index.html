Every property, lease and payment in one place.

A white-label, multi-tenant property management platform for South African rental agencies. Each agency runs the full rental lifecycle under its own brand and domain — tenants and owners never see Locare.

What you're looking at

Back-office

Next.js 14, App Router

Rent roll, proof-of-payment review, owner statements, and reporting with a real income statement.

Mobile

Tenant & landlord apps

React Native via Expo, sharing one themed component library with the back-office. Both white-labelled per agency.

Accounting

Immutable double-entry ledger

Every invoice, payment, deposit and payout posts through it. Corrections are new postings, never edits.

Architecture

Isolation in the database

Tenant separation enforced by PostgreSQL row-level security keyed on the vendor, not by application code.
